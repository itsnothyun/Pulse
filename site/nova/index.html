Ecosystem

Nova: Start it all. stop it all.

A personal AI command center for your development workspace. Editors, terminals, dev servers and AI agents start together, and stop together.

See what it does

Windows and macOS · desktop app, no sign-in · not released yet

What it does

Workspaces

An ordered list of actions that start and stop together: apps, URLs, commands, terminals and AI agents.

Projects

Register a repo once, with its commands and editor, and reuse it in any workspace.

Nova Assistant

A chat panel with real tool-calling. It can only use the same reviewed functions the interface does.

Automations

Schedules, workspace events, process exits and port changes can each run a routine.

Push-to-talk

Hold a hotkey, speak, and it lands in the chat. The microphone is open only while you hold the key.

System page

A live process list, disk usage and a safe cleanup of regenerable folders like node_modules.
