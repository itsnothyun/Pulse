The pulse of your machine.

A tiny monochrome widget for macOS and Windows. CPU, memory, temperature and disk at a glance, plus the Claude Code tokens you spent this week.

Star on GitHub Download

Free and open source · MIT · macOS 13+ · Windows 10 & 11

Everything at a glance.

One look tells you how the machine is doing. Point at a row to find it in the widget.

  • Processor

    Total load with a meter for every core, and the last thirty seconds as a trend.

  • Memory

    Matches Activity Monitor's “Memory Used”: app memory, wired and compressed.Physical memory in use against what's installed.

  • Temperature

    Read from the Apple Silicon SoC sensors, with the peak beside it.Read from the ACPI thermal zone. Some desktops don't report one, and Pulse says N/A rather than guess. The bar blinks when it runs hot.

  • Disk

    Free space on the startup volumesystem drive.

  • Graphics

    GPU load, from the IOAccelerator statisticsthe same GPU Engine counters Task Manager uses.

  • Network

    Download and upload per second across your physical connections.

  • SwapCommit

    How much memory has spilled to disk.Commit charge against the limit, Windows' measure of memory plus page file.

  • Power

    Battery level and whether it's charging, or AC on a desktop.

Read from your own disk.

Claude Code keeps a transcript of every session in ~/.claude/projects (or $CLAUDE_CONFIG_DIR). Pulse adds up the token usage on every response since Monday at midnight.

Counted once.

Responses are de-duplicated by message and request id. After the first scan, Pulse only reads what was appended, so the tally costs next to nothing.

Claude Code only: not the Claude desktop or web apps, and not your plan's limits. No account, no sign-in, no network requests.

Built to stay out of the way. Pulse refreshes once a second, idles at a few percent CPU, makes no network requests, and goes completely still when your system asks for reduced motion.

Install in a minute.

macOS

macOS 13 or later · Apple Silicon and Intel

  1. Download and unzip. Pulse for macOS.zip
  2. Move Pulse.app to Applications.
  3. Pulse isn't notarized yet, so clear the quarantine flag once:
    xattr -dr com.apple.quarantine /Applications/Pulse.app
  4. Open Pulse. It appears in the top-right corner.

Windows

Windows 10 or 11 · x64

  1. Download and unzip. Pulse for Windows.zip
  2. Run Pulse.exe. There's no installer, and .NET comes built in.
  3. The build isn't code-signed yet, so SmartScreen may warn you. Choose More info, then Run anyway.
  4. Pulse appears in the top-right corner.
Build it from source

macOS, with the Xcode command line tools:

git clone https://github.com/itsnothyun/pulse && ./pulse/macos/build.sh

Windows, with the .NET 8 SDK:

dotnet publish pulse/windows/Pulse/Pulse.csproj -c Release -r win-x64 --self-contained -p:PublishSingleFile=true -o out
