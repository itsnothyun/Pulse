Built into Windows.

Pulse Explorer sits in File Explorer's "Open with" menu and works the way the rest of Windows does.

Quick View, right where you clicked.

Double-click a file in File Explorer and a small preview opens beside that window. Press Esc to close it, or send it to the full workspace when you want to stay a while. Prefer tabs? Switch it in Settings.

Your recent files, already there.

The home screen lists what you opened lately in Windows, filtered to the types it can show and to files that still exist. No importing first.

Collections, notes and history.

Group files into collections, keep notes beside them, and pick up where you left off. All of it is stored in the app on your PC, and one click in Settings clears it.

One keystroke to anything.

Press Ctrl+K and the command palette searches files, places and actions as you type. From Quick View, one click shows the file in File Explorer or opens it in another app.

Set it as your default viewer.

The installer registers every supported type with its own pixel file icon. Pick Pulse Explorer in Windows Settings for the types you want, and it opens them from then on.

The Pulse look, all the way down.

Monochrome, a pixel font, quiet scanlines and motion that stops when Windows asks for reduced motion. Small, fast, and dark-first.

Your files stay yours.

There's no account and no cloud. Pulse Explorer reads a file from your disk, draws it, and that's all.

  • Nothing is uploaded. Every viewer runs inside the app, offline.
  • It checks what a file really is. Types are read from the file's own bytes, not trusted from its name.
  • Scripts are stripped. SVG, HTML, Markdown, eBooks and Word files are cleaned before they're shown.
  • Macros never run. Office macros are ignored, not executed.
  • Archives are fenced. Zip bombs and paths that climb out of the archive are blocked.
  • Secrets stay masked. Values in .env files are hidden until you choose to reveal them.
  • Least privilege. The app can open and read files you pick, and nothing more.

Install in a minute.

Windows

Windows 10 or 11 · x64 · 3.4 MB

  1. Download the installer. Pulse Explorer 1.0.0.exe
  2. The installer isn't code-signed yet, so SmartScreen may warn you. Choose More info, then Run anyway.
  3. It installs for your account only, so it doesn't ask for admin rights.
  4. Optional: in Pulse Explorer, open Settings → Default app to make it the viewer for the types you choose.

Check the download

    Get-FileHash .\PulseExplorer_1.0.0_x64-setup.exe
